# P-RANGER MINI V1 Flight Controller

**A fully tested, compact, high-performance 32-bit flight controller engineered for reliable UAV and airborne system integration.**

The **P-RANGER MINI V1.3** is a flight-proven avionics control board designed with robust power protection, comprehensive sensor fusion, and dual high-speed blackbox logging. Optimized for simple drone installation and multi-protocol hardware setup, the platform has undergone full bench-testing and successful flight validation on a quadcopter frame.

## ⚙️ Technical Specifications & Interfaces

### **Core Processing & I/O**
* **Main Processing Unit:** High-Performance 32-bit ARM Cortex-M4 Microcontroller
* **PWM Channels:** 7x Dedicated PWM outputs (Multirotors, Fixed-Wing, & Servos)
* **Serial Interfaces:** 3x Dedicated Hardware UARTs (Telemetry, GPS, & Receiver)
* **Bus Communication:** 2x SPI Buses + 1x I2C Bus for external expansion modules

### **Navigation & Sensors**
* **Onboard Sensor Suite:** Precision Gyro, Accelerometer, Barometer, and Digital Compass
* **GPS Compatibility:** Tested and optimized for u-blox GPS systems
* **RC Receiver Support:** Onboard hardware signal inverter for SBUS / IBUS integration

### **Storage, Power & Utilities**
* **Dual Blackbox Logging:** High-Speed Internal SPI Flash Memory + Onboard MicroSD Card Slot
* **Power Management:** Onboard clean power regulation circuit with filtering and protection
* **Acoustic & Visual Indicators:** Dedicated Active Buzzer driver port + Addressable LED Strip interface
* **Form Factor:** Ultra-compact footprint for quick and easy installation on standard drone frames
